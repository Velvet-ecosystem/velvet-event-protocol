# Memory Event Contract

Memory events carry public-safe references only.

They may include stable event identifiers, memory kind, confidence, authority status, receipt identifiers, and transparent recall score components.

They must not include private memory content, raw conversations, biometric detail, executor names, capabilities, commands, hardware targets, or authority tokens.

Recall results describe relevance. They do not establish truth or grant authority.

All memory events are read-only transport records. Court authorization and execution remain outside this contract.
